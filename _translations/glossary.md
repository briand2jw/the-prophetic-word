# Glossary: fixed terms for every language

Edit this file to fix how important words are translated. Add one line per term.
Format:  English term = how to write it in each language (es / hi / ar).
Every translation reads this file, so a correction here carries into new translations.

- The Pure Language = keep the name in English in every language (it is the site's name).
- Jehovah = es: Jehová / hi: यहोवा / ar: يهوه
- Bible book names = use the standard name in that language's widely used Bible.
- Scripture quotations = translate faithfully and conservatively; do not paraphrase,
  add, or remove anything. A reviewer will conform them to the chosen Bible.
- Verse references (for example Daniel 7:14) = keep the numbers and the colon; translate only the book name.
- Posted / Updated dates = write the date in that language's usual form.
