SUBMISSIONS: drop the writers' Word files here.

Each Word file starts from templates/The-Truth_Writer-Template.docx.
The details table at the top of the file says where the page goes,
so nothing here needs sorting into folders.

Using LibreOffice (or another program)? That works. Upload the file as Word (.docx) or
as LibreOffice (.odt). Either is read the same way. In LibreOffice, version 7.4 or newer
shows the dropdowns and date pickers.

Adding or changing a page: upload the file (Add file > Upload files).
Uploading a file with the same name replaces the old version.
Removing a page: open its file here and click the trash can icon.

The site rebuilds itself about 3 to 5 minutes after every upload.
If a file has a problem, it is skipped and the Actions tab shows why.
